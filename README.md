# 拨开世界之琴弦

跨端互动 Web 项目 — 毛玻璃摄像头 + 水墨刮刮乐 + 手势追踪琴弦拨奏

一场深度的世界音乐之旅，拨开迷雾，聆听六大古老乐器的灵魂之声。

## 六大乐器

| 场景 | 乐器 | 文化渊源 |
|------|------|----------|
| 桑图尔 · 波斯遗韵 | Santur（桑图尔） | 波斯扬琴，锤击弦鸣 |
| 西塔尔 · 恒河之诗 | Sitar（西塔尔） | 印度拨弦，瑜伽之音 |
| 乌德琴 · 沙漠月光 | Oud（乌德琴） | 阿拉伯琉特，沙漠诗篇 |
| 奈伊笛 · 苏菲低语 | Ney（奈伊笛） | 苏菲芦笛，灵魂呼吸 |
| 琵琶 · 东方叙事 | Pipa（琵琶） | 中国弹拨，大弦小弦 |
| 鲁巴布 · 喀布尔之歌 | Rubab（鲁巴布） | 阿富汗弹拨，山谷回响 |

## 核心视觉效果

1. **沧桑毛玻璃摄像头**：实时摄像头流以 `blur(25px) grayscale(30%)` 渲染，叠加噪点纹理
2. **水墨擦除穿透**：拨弦时在手指位置生成水墨掩码，穿透毛玻璃露出清晰乐器画面
3. **高弹性阻尼震动**：初始振幅 8%~10% 屏宽，衰减 0.96，余震持续 ~1.2 秒
4. **指尖星尘 + 爆裂粒子**：暗金色悬浮星尘 + 15 粒金色音符爆裂
5. **电影级黑场过渡**：1.5 秒音画双渐隐

## 状态机

```
idle → loading → playing → settling → waving → settling → idle
```

- **idle**：启动界面
- **loading**：场景过渡加载
- **playing**：玩家拨弦交互
- **settling**：通关结算，水墨展开
- **waving**：等待玩家点击进入下一场景

## 项目结构

```
├── index.html      — 全屏 Canvas + 黑场过渡 + 启动遮罩
├── audio.js        — AudioManager 双通道原始采样
├── canvas.js       — CanvasManager 毛玻璃 + 水墨 + 阻尼震动
├── app.js          — AppCore 状态机 + 碰撞检测
├── images/         — 6 张乐器背景图
├── audio/          — 音频资源（MP3 格式）
└── video/          — （可选）乐器演奏视频
```

## 音频架构

click / pluck 全局共用一套，只有 end（结算音乐）按场景区分：

```
audio/
├── bgm_start.mp3   — 主界面背景音乐（循环播放，开始后淡出）
├── click.mp3       — 击弦音头（共用）
├── pluck_1.mp3     — 琴弦共鸣变体 1（共用）
├── pluck_2.mp3     — 琴弦共鸣变体 2（共用）
├── pluck_3.mp3     — 琴弦共鸣变体 3（共用）
├── e_santur.mp3    — 桑图尔 结算音乐
├── e_sitar.mp3     — 西塔尔 结算音乐
├── e_oud.mp3       — 乌德琴 结算音乐
├── e_ney.mp3       — 奈伊笛 结算音乐
├── e_pipa.mp3      — 琵琶 结算音乐
└── e_rubab.mp3     — 鲁巴布 结算音乐
```

## 渲染管线（每帧从底到顶）

```
Layer 1  乐器背景（cover + 暗角）
Layer 2  毛玻璃摄像头（blur 25px + grayscale 30% + 噪点）
Layer 3  清晰摄像头（仅在水墨擦除区域显现）
Layer 4  琥珀暗角蒙版
Layer 5  震动琴弦（三层：主弦 + 高光 + 虚影拖尾）
Layer 6  粒子（星尘 + 爆裂）
```

## 启动方式

```bash
# 需要 HTTPS 或 localhost 才能访问摄像头
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```
