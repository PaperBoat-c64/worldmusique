## 建议规格

- **格式**：JPEG（.jpg）
- **分辨率**：1920×1080 或更大（16:9 或接近比例）
- **内容**：乐器特写或演奏场景，色调偏暗以配合毛玻璃叠加效果
- **大小**：建议 < 2MB，过大影响加载速度

## 图片来源建议

- [Unsplash](https://unsplash.com/) — 免费高质量摄影
- [Pexels](https://www.pexels.com/) — 免费图片素材
