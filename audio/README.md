## 建议规格

- **格式**：MP3（.mp3）
- **采样率**：44100 Hz 或 48000 Hz
- **比特率**：128~320 kbps
- **共享音效**：短促（< 1 秒），延迟低
- **结算音乐**：15~30 秒，旋律/氛围性强，渐入渐出友好
- **BGM**：可循环，建议 1~3 分钟
